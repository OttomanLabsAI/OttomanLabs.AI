pyGherkin

A pyRevit extension that rebuilds this tower in Revit. Design the model here, export the CSV data, and pyGherkin reconstructs the levels, diagrid framing and connection nodes inside your Revit project.

↓  Download pyGherkin extension .zip · pyRevit extension · v1.0

What it does

Once you’ve drawn a tower on the Exoskeleton and Floors tabs, the dashboard exports three CSV files — levels, framing and connections. pyGherkin reads them and builds the model in Revit: it creates the storey levels, places the diagonal framing members on their host levels with the correct cross-section rotation, and drops a connection node at every diagrid hub. Re-running after a tweak updates what’s there, so you can iterate between the dashboard and Revit.

You’ll need pyRevit

pyGherkin runs inside pyRevit, a free add-in that hosts Python tools on the Revit ribbon. Install pyRevit first, then drop the pyGherkin extension into your pyRevit extensions folder and reload — a pyGherkin tab appears in Revit with the import buttons.

Download pyRevit ↗ pyRevit docs ↗

Free — no licence required

Both pyGherkin and pyRevit are free and open-source. There is no licence to buy, no subscription, and no activation — you only need a working copy of Autodesk Revit for pyRevit to run inside. Download both, install, and go.
